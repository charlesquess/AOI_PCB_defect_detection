# 串口通信协议文档 — PCB 缺陷检测系统

## 物理层

| 参数 | 值 |
|------|-----|
| 接口 | RS232 / RS485 |
| 波特率 | 9600（可配置 `config.yaml`） |
| 数据位 | 8 |
| 校验位 | N（无） |
| 停止位 | 1 |

## 通信模式

### 1. 触发模式（产线标准）

PLC 发送触发信号，系统采集一帧 → 推理 → 回传结果。

```
PLC ──TRIG──→ 检测系统
                  │
                  ├── 采集一帧
                  ├── 滑窗推理
                  ├── NMS 融合
                  │
检测系统 ──PASS──→ PLC   (无缺陷)
检测系统 ──FAIL:n──→ PLC  (n 个缺陷)
检测系统 ──DONE──→ PLC   (本次处理完成)
```

**时序：**
```
TRIG  → [采集+推理] → PASS/FAIL:n → DONE  → 等待下一 TRIG
      <─── 整体 ≤500ms ───>
```

### 2. 连续模式（调试 / 演示）

系统连续采集推理，IOU 追踪去重，仅新 PCB 回传结果，无需 TRIG 信号。

## 报文格式

### PLC → 检测系统（下行）

| 报文 | 说明 | 示例 |
|------|------|------|
| `TRIG\n` | 触发信号（触发模式） | `TRIG` |
| `STAT\n` | 查询统计摘要（保留） | `STAT` |
| `RST\n`  | 重置统计计数 | `RST` |

### 检测系统 → PLC（上行）

| 报文 | 说明 | 示例 |
|------|------|------|
| `PASS\n` | 良品，未检出缺陷 | `PASS` |
| `FAIL:<n>\n` | 缺陷品，n = 当前帧缺陷数 | `FAIL:2` |
| `DONE\n` | 本次触发处理完成（触发模式） | `DONE` |
| `STAT:<total>,<pass>,<fail>,<yield_pct>\n` | 统计摘要（响应 STAT） | `STAT:150,142,8,94.67` |

## 超时与错误处理

| 场景 | 行为 |
|------|------|
| 串口打开失败 | 日志记录错误，程序继续运行（无串口模式） |
| 发送失败 | 日志记录警告，不重试 |
| 接收超时 (50ms) | 返回空，继续轮询 |
| TRIG 后推理超时 (>5s) | 回传 `FAIL:0` + `DONE` |
| 异常断线 | 下次发送失败时记录日志，不自动重连 |

## 状态机

检测系统内部的串口通信状态机跟踪触发模式的完整生命周期：

```
                  ┌──────────────────────────────┐
                  │          空闲 (Idle)           │
                  │  连续模式：连续推理，有新缺陷时  │
                  │  自动回传 PASS/FAIL            │
                  └──────────┬───────────────────┘
                             │ 收到 TRIG（触发模式）
                             ▼
                  ┌──────────────────────────────┐
                  │       等待 TRIG (WaitingTrig)  │
                  │  采集线程轮询串口，等待 PLC     │
                  │  发送 TRIG 信号                │
                  └──────────┬───────────────────┘
                             │ TRIG 到达
                             ▼
                  ┌──────────────────────────────┐
                  │        推理中 (Inferring)       │
                  │  采集一帧 → 滑窗推理 → NMS 融合  │
                  └──────────┬───────────────────┘
                             │ 推理完成
                             ▼
                  ┌──────────────────────────────┐
                  │       回传结果 (Reporting)      │
                  │  PASS / FAIL:n / DONE          │
                  └──────────┬───────────────────┘
                             │ 回传完成
                             ▼
                  ┌──────────────────────────────┐
                  │          空闲 (Idle)           │
                  │  等待下一触发 / 连续推理         │
                  └──────────────────────────────┘
```

**超时处理**: 推理超过 5 秒 → 回传 `FAIL:0` + `DONE` → 回到空闲。

**串口未连接**: 状态保持在 `Disconnected`，不发送任何消息，程序以降级模式运行（仅 UI + 统计）。

## 时序图

触发模式下完整的信号交互时序：

```
PLC                         检测系统
 │                            │
 ├── TRIG ──────────────────► │  [状态: 等待TRIG → 推理中]
 │                            │  ┌─ 采集一帧
 │                            │  ├─ 滑窗推理
 │                            │  └─ NMS 融合
 │                            │  [状态: 回传结果]
 │◄── PASS / FAIL:n ─────────┤
 │◄── DONE ──────────────────┤  [状态: 空闲]
 │                            │
 ├── TRIG ──────────────────► │  下一循环...
 │                            │
 │            ...             │
 │                            │
 ├── RST ────────────────────► │  重置统计计数
 │                            │
 ├── STAT ───────────────────► │  查询统计摘要
 │◄── STAT:total,pass,fail...─┤
```

## 使用 com0com 调试

```powershell
# 安装 com0com 后生成 COM5 ↔ COM6 对
# 终端 1: 检测系统 (接 COM6)
cd defect_detection
.\build\Release\defect_detection.exe config\config.yaml

# 终端 2: PLC 模拟器 (接 COM5)
conda run -n yolov5 python scripts/plc_simulator.py COM5 --interval 2.0
```

PLC 模拟器支持以下命令（在控制台输入）：

| 命令 | 说明 |
|------|------|
| `TRIG` | 发送触发信号 |
| `STAT` | 查询统计摘要 |
| `RST`  | 重置统计计数 |
| `Q`    | 退出模拟器 |

## MCU 参考实现 (Arduino 伪代码)

```cpp
void loop() {
    // 发送触发
    Serial.println("TRIG");
    
    // 等待结果（超时 3s）
    unsigned long t = millis();
    while (millis() - t < 3000) {
        if (Serial.available()) {
            String line = Serial.readStringUntil('\n');
            if (line.startsWith("PASS")) {
                digitalWrite(GREEN_LED, HIGH);
            } else if (line.startsWith("FAIL")) {
                digitalWrite(RED_LED, HIGH);
            }
        }
    }
    delay(500);  // 产线节拍
}
```
